# Curso de HTML5

Exercícios feitos durante meus estudos de HTML5 e CSS, organizados por aula. Os projetos foram criados com Angular, uma ferramenta para construir sites.

## O que tem aqui

- `aula01-02`: exercícios das aulas 1 e 2
- `aula03-04`: exercícios das aulas 3 e 4
- `exerciciodeavaliacao`: meu portfólio pessoal, criado como exercício de avaliação

## O que aprendi

- Estruturar páginas com HTML5
- Estilizar páginas com CSS
- Organizar vários projetos Angular em um só repositório
- Usar Git e GitHub para guardar e enviar meus projetos

## Tecnologias usadas

- HTML5
- CSS
- Angular
- Git e GitHub

## Como ver o resultado

1. Baixe os arquivos deste repositório.
2. No terminal, entre na pasta do projeto que deseja ver.
3. Rode `npm install` para instalar o que o projeto precisa.
4. Rode `npm start` para iniciar o projeto.
5. Abra `http://localhost:4200` no navegador.
